# 组织资源作用域盘点

统一规则：组织上下文必须由有效任职解析；读取使用当前节点及全部有效后代节点集合；同级、跨公司和其他兼职任职不会并入集合；新增资源归属当前节点。个人层资源若有 `owner_id`，必须同时匹配当前用户。

## 已纳入纵向读取

- 文档、分块、FTS、SQLite/Qdrant 向量检索和 Agent 文档工具
- 会话及消息（个人层同时限制所有者）
- 审批任务、审批事件、执行结果、备份和操作审计日志
- 用量、降级事件、配额汇总
- 发票、发票明细和支付查询
- 站内通知（定向通知仍只对接收人可见）和通知端点列表
- 审批策略列表与策略命中计算
- 前端异常/性能遥测列表

## 当前节点写入或变更

- 文档上传、聊天消息、通知偏好、配额设置、策略创建/版本/启停、遥测上报
- 组织资源变更必须显式通过角色、层级、父子关系和可见节点校验
- 原始目标数据库浏览与连接配置保持当前节点限定；父节点不能借“向下可见”隐式取得子节点数据库凭据

## 身份私有资源

- 用户记忆和用户画像始终同时限制 `owner_id`。它们不是部门共享知识；管理层纵向权限不会覆盖个人隐私边界。
- 定向通知同样保留接收人条件。

## 后台任务

- 审批过期、执行 Saga 修复、通知投递和备份任务使用资源自身持久化组织 ID，不使用调度 worker 的当前请求上下文。
- 数据库连接缓存键为组织 ID、任职 ID、配置版本；任职或配置切换不会复用旧连接。

## 审计上下文

- 组织节点和任职的创建、修改、移动、停用、主职切换及上下文切换事件统一记录 actor、company、organization、membership、request ID、来源 IP、时间和结果。
- 兼容 `X-Tenant-ID` 与已验证组织上下文不一致时记录拒绝事件；不得在事件中保存令牌、密码或数据库凭据。
