## 技术栈与版本基线

以下版本以当前项目配置和 CI 为准；生产数据库与缓存是组织隔离验收的组成部分，不得只以单进程 SQLite 测试代替。

- **语言与运行时**：Python `>=3.12,<3.15`，CI 固定 Python 3.12，Uvicorn `>=0.30`。
- **Web/API**：FastAPI `>=0.115`、Pydantic `>=2.10`、pydantic-settings `>=2.7`，OpenAPI 作为前后端契约来源。
- **ORM 与事务**：SQLAlchemy Async `>=2.0.36`、`AsyncSession`、显式事务和行级锁；禁止在路由内维护第二套组织过滤逻辑。
- **Schema 迁移**：Alembic `>=1.14`；每次结构变更必须同时提供 upgrade、downgrade、预检查和数据校验。
- **内部数据库**：SQLite + aiosqlite 仅用于开发/快速单测；生产验收使用 PostgreSQL 17 + asyncpg `>=0.30`，数据库约束和并发锁以 PostgreSQL 结果为准。
- **目标业务数据库**：SQLite、MySQL 8.4 + aiomysql `>=0.2`、PostgreSQL 17 + asyncpg；连接池按公司、组织、Membership、配置版本隔离。
- **缓存与多 Worker 协调**：Redis Server 7.x、redis-py asyncio `>=5.0`；用于上下文版本、令牌撤销、缓存失效和跨 Worker 通知。
- **认证与上下文令牌**：现有 `hmac`/`hashlib`/`base64` HMAC-SHA256 签名体系；组织令牌必须包含 `jti`、`iat`、`exp`、用户、公司、组织、Membership、角色和 context version，禁止仅签名裸组织 ID。
- **流式与 HTTP**：sse-starlette `>=2.0`、httpx `>=0.25`；SSE 订阅保存并校验组织上下文版本。
- **加密**：cryptography `>=41` 与项目版本化 keyring；数据库凭据和敏感配置不得明文落库。
- **测试**：pytest、pytest-asyncio、FastAPI/httpx 测试客户端；本整改新增 pytest-cov 用于组织模块覆盖率门禁。
- **质量与 CI**：Ruff、`python -m compileall`、GitHub Actions；真实集成环境使用 PostgreSQL 17、MySQL 8.4、Redis 7.x。

### 需要新增并锁定的开发依赖

- `pytest-cov`：组织模块 statement/branch coverage 门禁；加入开发依赖或 CI 安装步骤，不进入生产镜像。
- PostgreSQL、MySQL、Redis 均以 CI service container 启动并固定镜像版本，禁止使用`latest`。
- 不新增第二套ORM、认证框架或缓存客户端；确需新增依赖时必须记录用途、许可证、版本和安全扫描结果。
